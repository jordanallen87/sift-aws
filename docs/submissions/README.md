## Submission discipline

- Verify the public repository and live URL from an incognito window.
- Keep fixture and live-mode claims distinct.
- Show the working product before architecture slides.
- Do not claim AgentCore, ChatGPT-host, or browser testing that was not actually completed.
- After each competition deadline, do not edit the submitted project, repository, live site, form, or video until the organizer permits it.
